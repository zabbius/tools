# tools

Коллекция мелких утилит для Linux. Каждая утилита — самостоятельный bash-скрипт в своём каталоге, без общего билд-степа и без зависимостей между утилитами. Для каждого тула есть свой README с примерами использования.

Инструкции для AI-агентов — [AGENTS.md](AGENTS.md); внутренняя документация (спеки) — [specs/INDEX.md](specs/INDEX.md).

## Каталог

### network

| Тул | Описание |
|---|---|
| [netns-run](network/netns-run/) | Запуск произвольной команды в изолированном network namespace с принудительным направлением всего её трафика через заданный шлюз (второй провайдер, VPN, отдельная сетевая карта), не меняя маршрутизацию хоста. Окружение полностью очищается после завершения. Подробности — [network/netns-run/README.md](network/netns-run/README.md). |
